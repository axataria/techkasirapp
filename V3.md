# TechKasir V3 · 3.0.0

V3 adalah versi aktif aplikasi: Next.js App Router, React, TypeScript, Tailwind CSS v4, dan komponen resmi shadcn/ui. Tampilan glassmorphism, mode terang/gelap, dan pilihan palet tetap tersedia. Identitas V3 tampil pada judul browser dan footer.

## Menjalankan aplikasi

Memerlukan Node.js 24 atau lebih baru. Pada Windows gunakan `npm.cmd`.

```powershell
npm.cmd install
npm.cmd run dev
```

Port default adalah 3100. Untuk menggunakan alamat workspace yang sedang dipakai:

```powershell
$env:PORT='3100'
npm.cmd run dev
```

Untuk menjalankan build produksi lokal:

```powershell
npm.cmd run build
$env:PORT='3100'
npm.cmd start
```

Hentikan proses aplikasi sebelumnya pada port yang sama sebelum menjalankan ulang. Saat ini aplikasi utama menggunakan `http://127.0.0.1:3100`, dengan database `data/store.db`. Akun toko yang sudah ada tetap dipakai. Tidak ada password admin bawaan baru untuk V3.

## Fungsi yang tersedia

- Setup toko, login/logout, hak akses pemilik/kasir/staf servis, pengelolaan staf dan audit.
- Dasbor operasional, pencarian database, profil pelanggan, katalog dan unit fisik.
- Supplier, penerimaan draf/finalisasi, QC, stok siap jual, dan perjalanan unit.
- Kasir satu unit per transaksi, kanal penjualan, pembayaran tunai/transfer/QRIS, DP, pelunasan, serta invoice dan bukti pembayaran.
- Servis pelanggan, estimasi, biaya, status pekerjaan, uang muka dan invoice akhir.
- Garansi, retur pelanggan/supplier, kredit retur dan pembayaran refund.
- Keuangan, laporan periode/bulanan, ekspor CSV, saldo awal, dan kebijakan garansi.

Aturan dan batas MVP bisnis tetap mengikuti [V2.md](V2.md). Jalur API `/api/v2/*` dan tabel `v2_*` dipertahankan untuk kompatibilitas data; angka itu bukan versi frontend yang ditampilkan.

## Perbaikan fungsional V3

- Memperbaiki kegagalan server saat tambah, arsipkan, atau aktifkan produk akibat variabel ID yang menutupi ID rute.
- Memilih produk katalog pada penerimaan otomatis mengisi kategori, model dan spesifikasi melalui state React.
- Memilih ulang unit yang sama tidak menghapus input draft kasir.
- Setelah penjualan berhasil tersimpan, draft dibersihkan sebelum pembacaan ulang data. Gangguan pembacaan ulang tidak menampilkan transaksi yang sudah berhasil sebagai transaksi yang perlu dikirim ulang.
- Hasil pencarian memperbarui pilihan pesanan/pelanggan/unit pada halaman yang sedang terbuka; sesi yang kedaluwarsa saat memuat data kembali menampilkan login.
- Shell navigasi tetap terpasang saat berpindah bagian. Area konten memiliki scroll terpisah dan ruang scrollbar tetap. Penguncian scroll dialog tetap aktif.

## Verifikasi

```powershell
npm.cmd run verify
```

Perintah ini memeriksa TypeScript, membuat build produksi, menjalankan delapan rangkaian regresi yang sudah ada, dan menjalankan integrasi Next.js V3. Semua pengujian transaksi memakai database sementara, terpisah dari database toko utama.

Integrasi V3 memeriksa route/aset, login dan cookie, proteksi origin, produk/arsip, supplier/penerimaan/QC, penjualan DP yang idempoten, pelunasan, invoice, pencarian, penyelesaian servis, garansi, laporan, serta pembatasan akses kasir. Pengujian UI lama dalam `qa/legacy-frontend` adalah fixture historis, bukan bukti pengujian komponen React baru.

Pemeriksaan browser V3 memverifikasi login, navigasi katalog, tambah produk, pengisian otomatis penerimaan, simpan draf, dan finalisasi menjadi Diterima. Pemeriksaan browser sebelumnya juga mencakup kasir tunai, detail pesanan, pencarian, dan kestabilan lebar saat dialog/menu dibuka. Setiap kombinasi perangkat dan setiap dialog belum diuji secara manual.

## Preview terpisah

Setelah build, jalankan `npm.cmd run preview`. Preview memakai database sementara dan port 3101, dengan username `preview` serta password `preview-v3-only-2026`. Bila port sudah dipakai, atur `PREVIEW_PORT` terlebih dahulu. Akun preview tidak berlaku pada database toko utama.

## Struktur

Frontend dan backend adalah satu proyek dengan satu `package.json`, satu entry point `server.mjs`, dan satu port utama 3100. Tidak diperlukan server API terpisah. `scripts/api-test-server.mjs` hanya harness pengujian/seed; bukan aplikasi kedua. Nama V2 pada API dan tabel dipertahankan untuk kompatibilitas data.

- `src/app`: layout dan route Next.js.
- `src/components/ui`: source shadcn/ui yang disesuaikan dengan token aplikasi.
- `src/components`: shell, formulir, tabel, dan layar bisnis React.
- `src/lib`: API, preferensi tampilan, utilitas, serta identitas versi.
- `server.mjs`: satu origin untuk Next.js, API toko, dan dokumen cetak.
- `src/server/store.mjs`, `src/server/operations.mjs`, `shared/domain.mjs`: backend dan aturan bisnis SQLite.

V3 masih merupakan build lokal. Batas MVP, kebutuhan backup terjadwal, HTTPS/hosting, dan fungsi yang belum tersedia tetap berlaku seperti yang dijelaskan di README dan V2.
